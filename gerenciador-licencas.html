📖 Como Usar Este Gerenciador

1️⃣ Quando um cliente paga:

  • Preencha os dados do cliente acima
  • Clique em "Gerar Código"
  • Copie o código e envie por email
  • O cliente cola o código em acesso-premium.html para desbloquear

2️⃣ Como compartilhar o código com cliente:

Email sugerido:

"Olá [NOME],

Seu pagamento foi confirmado! 🎉

Para desbloquear o acesso permanente à EventCalc Pro v7, use este código:

[CÓDIGO]

Acesse: seu-site.com/acesso-premium.html e cole o código no campo de ativação.

Dúvidas? Responda este email ou entre em contato via WhatsApp.

Abraços!"

3️⃣ Teste de expiração:

  • A data de expiração é calculada automaticamente (dias fornecidos)
  • Passada a data, o cliente vê tela de "Período Expirado" e volta para upgrade
  • Você pode criar um código com 7 dias para testar o aviso antes de expiração

⚠️ Importante:

  • Não compartilhe códigos de teste publicamente
  • Cada código pode ser ativado múltiplas vezes (sem limite de reutilização)
  • Se quiser restrição de 1 cliente/código, você precisará de backend (banco de dados)
  • Para agora, recomendo: use códigos únicos por cliente + confiança
