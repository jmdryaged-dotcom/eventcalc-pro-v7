🧮 CÁLCULOS IMPLEMENTADOS
═════════════════════════════════════════════════════════════════════════════════

VOLUME META (do questionário):
  Meta_por_categoria = g/pessoa × número_pessoas ÷ 1000

TABELA DE VOLUMES:
  A_Comprar = Kg_Servir ÷ (1 - Perda%/100)
  Total_R$ = A_Comprar × R$/kg

CUSTOS (em proposta):
  Matéria-Prima = soma de todos os itens
  Carvão = Matéria × 0.10
  Temperos = Matéria × 0.05
  Descartáveis = Matéria × 0.08
  
  Subtotal_Operacional = Carvão + Temperos + Descartáveis
  
  Chef = R$ 400,00 (padrão)
  Auxiliares = R$ 100 (até 30 pessoas) ou R$ 200 (acima de 30)
  Subtotal_MaoObra = Chef + Auxiliares
  
  Custo_Total = Matéria + Subtotal_Operacional + Subtotal_MaoObra
  Lucro = Custo_Total × 0.25
  Impostos = Custo_Total × 0.15
  
  VALOR_FINAL = Custo_Total + Lucro + Impostos

📋 COMO USAR (Passo a Passo)
═════════════════════════════════════════════════════════════════════════════════

PASSO 1: Abrir o Aplicativo
  └─ Clique em: ABRA_AQUI_v7.html
  └─ Ou abra: index_v7.html
  └─ Você verá a landing page com seu perfil

PASSO 2: Começar um Orçamento
  └─ Clique em "Começar Agora"
  └─ Vai para Tela 1 (Questionário)

PASSO 3: Preencher Questionário
  └─ Local: Itapema/SC
  └─ Data: Escolha
  └─ Horário: Escolha
  └─ Duração: Ex: 4 horas
  └─ Refeição: Almoço (volumes se atualizam)
  └─ Pessoas: 20 adultos, 0 crianças
  └─ Equipamentos: Marque quais tem
  └─ Volumes aparecem com valores padrão
  └─ Pode EDITAR cada volume
  └─ TOTAL calcula automaticamente
  └─ Clique: Prosseguir para Cardápio

PASSO 4: Montar Cardápio
  └─ Adicione itens em cada categoria
  └─ Exemplo: Chouripan, Linguicinha, Costela, Batata, Salada, Torta
  └─ Cada item aparece com botão Remover (X)
  └─ Clique: Prosseguir para Volumes

PASSO 5: Preencher Volumes
  └─ Itens carregam automaticamente
  └─ Coluna direita mostra META: 19,4kg (970g × 20)
  └─ Preencha a tabela esquerda:
     • Linguicinha: 2.4kg @ R$ 25
     • Costela: 4.0kg @ R$ 80
     • Frango: 2.0kg @ R$ 18
     • Batata: 1.5kg @ R$ 8
     • ... resto dos itens
  └─ Perda% padrão 10% (pode alterar)
  └─ "A Comprar" calcula automaticamente
  └─ "Total" calcula automaticamente
  └─ Coluna centro mostra resumo por categoria
  └─ Equilibre para ficar próximo à meta
  └─ Clique: Prosseguir para Proposta

PASSO 6: Escolher Relatório
  └─ Opção 1: "Relatório do Assador" (interno com custos)
  └─ Opção 2: "Proposta do Cliente" (comercial)

PASSO 7: Exportar PDF
  └─ Clique: "Exportar PDF"
  └─ PDF é gerado com nome personalizado
  └─ Ex: "Compras_Itapema.pdf" ou "Proposta_Itapema.pdf"
  └─ Arquivo vai para Downloads
  └─ Abra e verifique conteúdo
