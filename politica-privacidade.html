🔒 Política de Privacidade

Última atualização: Maio de 2026

1. Introdução

A EventCalc ("nós", "nosso" ou "aplicação") respeita a privacidade dos usuários. Esta Política de Privacidade explica como coletamos, usamos, protegemos e compartilhamos dados.

Estamos em conformidade com a Lei Geral de Proteção de Dados (LGPD) - Lei nº 13.709/2018.

2. Dados Coletados

Nossa aplicação coleta os seguintes dados:

  • Dados de Orçamento: Local, data, horário, duração, tipo de evento, número de pessoas, cardápio, volumes de alimentos, preços — armazenados localmente no seu navegador (localStorage).
  • Dados de Contato (Opcional): Se você preencher o formulário de tutorial gratuito, coletamos nome, email e WhatsApp para enviar o material e fazer contato comercial.
  • Dados de Ativação de Licença (se aplicável): Quando você ativa uma licença paga, registramos endereço IP, tipo de navegador e dispositivo para detectar compartilhamento indevido. Estes dados ficam armazenados no seu próprio navegador.
  • Dados Técnicos: Apenas para fins de funcionamento da aplicação.

3. Como Usamos os Dados

Os dados são usados exclusivamente para:

  • Calcular orçamentos de eventos
  • Gerar propostas profissionais em PDF
  • Enviar o tutorial gratuito por email (via Resend, provedor de email transacional)
  • Contato comercial (caso você tenha solicitado)
  • Detectar compartilhamento indevido de licenças (quando aplicável)
  • Armazenar seus orçamentos no seu navegador para futuras consultas

4. Armazenamento de Dados

Importante: Seus dados são armazenados:

  • Primariamente: No seu navegador (localStorage) — você tem controle total e pode apagar a qualquer momento (botão no item 8).
  • Provedor de Email (Resend): Quando você solicita o tutorial, seu email é enviado para o serviço Resend (resend.com) apenas para entrega do material. O Resend tem sua própria política de privacidade e segue padrões internacionais.
  • Nunca: Seus dados não são vendidos ou compartilhados com terceiros para fins de marketing.

5. Seus Direitos (LGPD)

Você tem direito a:

  • Acesso: Saber quais dados temos seus
  • Correção: Corrigir dados imprecisos
  • Exclusão: Pedir que deletemos seus dados ("direito ao esquecimento")
  • Portabilidade: Receber seus dados em formato estruturado
  • Revogação: Revogar consentimento a qualquer momento

6. Cookies e Tecnologias Similares

A aplicação NÃO utiliza cookies de rastreamento publicitário. Utilizamos apenas:

  • localStorage: Para armazenar seus orçamentos, preferências e consentimento desta política. Fica apenas no seu navegador.
  • Detecção de IP (somente se ativar licença paga): Para coibir compartilhamento de licenças. Não usamos seu IP para rastrear navegação fora do nosso site.

7. Segurança

Implementamos medidas de segurança para proteger seus dados:

  • Criptografia de dados em transmissão (HTTPS)
  • Acesso restrito ao banco de dados
  • Nenhum compartilhamento com terceiros

8. Deletar Seus Dados (Direito ao Esquecimento - LGPD)

Você pode deletar seus dados a qualquer momento das seguintes formas:

  • Botão automático abaixo: Apaga TUDO que está no seu navegador relacionado ao EventCalc com 1 clique.
  • Manualmente: Limpar cache/localStorage do navegador.
  • Para dados de contato fornecidos (email/WhatsApp): Envie um pedido para jm.dryaged@gmail.com com o assunto "Solicitação LGPD - Excluir Dados". Atenderemos em até 15 dias úteis, conforme exige a LGPD.

🗑️ Apagar todos os meus dados deste navegador

Esta ação remove permanentemente: orçamentos salvos, dados profissionais, cardápios, consentimentos e licenças. Não há volta.

8.1 Tempo de Retenção

Dados de contato coletados (email/WhatsApp) ficam retidos por até 2 anos após o último contato, salvo solicitação de exclusão antecipada.

Dados de licença ficam retidos enquanto a licença estiver ativa + 1 ano para fins de auditoria fiscal.
