🔒 Política de Privacidade

Última atualização: Maio de 2026

1. Introdução

A EventCalc Pro v7 ("nós", "nosso" ou "aplicação") respeita a privacidade dos usuários. Esta Política de Privacidade explica como coletamos, usamos, protegemos e compartilhamos dados.

Estamos em conformidade com a Lei Geral de Proteção de Dados (LGPD) - Lei nº 13.709/2018.

2. Dados Coletados

Nossa aplicação coleta os seguintes dados:

  • Dados de Orçamento: Local, data, horário, duração, tipo de evento, número de pessoas, cardápio, volumes de alimentos, preços
  • Dados de Navegação: Armazenados LOCALMENTE no seu navegador (localStorage) - não enviados a servidores
  • Dados Técnicos: Apenas para fins de funcionamento da aplicação

3. Como Usamos os Dados

Os dados são usados exclusivamente para:

  • Calcular orçamentos de eventos
  • Gerar propostas profissionais
  • Melhorar a experiência do usuário
  • Armazenar seus orçamentos para futuras consultas

4. Armazenamento de Dados

Importante: Seus dados são armazenados:

  • Primariamente: No seu navegador (localStorage) - você tem controle total
  • Opcionalmente: Em banco de dados remoto (Firebase) - apenas se você escolher salvar na nuvem
  • Nunca: Seus dados não são compartilhados com terceiros sem sua permissão

5. Seus Direitos (LGPD)

Você tem direito a:

  • Acesso: Saber quais dados temos seus
  • Correção: Corrigir dados imprecisos
  • Exclusão: Pedir que deletemos seus dados ("direito ao esquecimento")
  • Portabilidade: Receber seus dados em formato estruturado
  • Revogação: Revogar consentimento a qualquer momento

6. Cookies

A aplicação NÃO utiliza cookies de rastreamento. Apenas armazena dados essenciais para funcionamento:

  • Dados de orçamento (localStorage)
  • Preferências de usuário

7. Segurança

Implementamos medidas de segurança para proteger seus dados:

  • Criptografia de dados em transmissão (HTTPS)
  • Acesso restrito ao banco de dados
  • Nenhum compartilhamento com terceiros

8. Deletar Seus Dados

Você pode deletar seus dados a qualquer momento:

  • Dados locais: Limpar cache do navegador
  • Dados na nuvem: Contate-nos em jm.dryaged@gmail.com
